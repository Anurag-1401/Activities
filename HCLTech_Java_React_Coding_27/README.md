## Java
`java/HCLCodingPractice.java` contains 22 Java exercises: 16 DSA/array/string problems and 6 Java-specific exercises.

Compile and run:
```bash
cd java
javac HCLCodingPractice.java
java HCLCodingPractice
```
File methods use Java 11+.

Assumptions:
- `missingNumber`: values are from 1 to n, with one missing.
- `subarrayWithSumPositive`: array contains positive numbers only. For negative numbers, use prefix sums and a HashMap.
- `secondLargest`: returns null if there is no second distinct value.
- `longestEqualZeroOne`: input is a binary array (only 0 and 1).

## React
Copy `react/src` into the `src` folder of a React/Vite project. Components use React hooks and require no extra library.
