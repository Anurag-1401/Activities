User Authentication with Password Policy and MFA

This front-end-only educational project demonstrates registration, password policy validation, password verification, failed-attempt lockout, OTP-based MFA, protected dashboard access, and logout.

1. Password Policy

Minimum 8 characters, uppercase, lowercase, digit and special character.

2. Account Lockout

Account locks for 10 minutes after 5 failed password attempts.

3. MFA

Password is followed by a one-time 6-digit OTP verification.
